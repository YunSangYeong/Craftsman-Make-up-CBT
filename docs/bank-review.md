# 1,000문항 문제은행 내부 검토 기록

기존 90문항 + 추가 910문항 = 기본 JSON 1,000문항. 부족 0, 기본 검증 대기 0.
원문 기출 0, 복원 0, 자체 제작 1,000, 계산 0, 숫자 조건 변형 0, 수치 변형 family 0.

## 작성 방식과 한계

추가 원고는 91개 단원에 서로 다른 설명 10개씩을 직접 작성한 것이다.
원고 한 줄로 한 문제만 만들고, 같은 줄의 역질문·보기 순열·숫자 치환으로 추가 문항을 만들지 않는다.
모두 난이도 하의 개념·작업 설명 판별형이며 서술형이나 공식 기출의 재현이 아니다.
정답과 같은 단원의 다른 세 항목을 보기로 내고 해설에는 정답 근거와 세 오답 개념의 차이를 제공한다.
같은 상위 개념의 적용 상황은 여러 번 등장할 수 있어 1,000개의 독립 개념을 확보했다는 뜻은 아니다.
서술형 작업 이름 일부는 학습 설명을 위한 일반적인 표현이며 법정·공식 전문용어라고 주장하지 않는다.

AI 일반 지식으로 작성하고 작성 에이전트가 개념·문장·선택지 관계를 내부 검토했다.
읽지 않은 외부 교재나 공식 자료를 인용하지 않았다. sourceUrl은 실제 원고 위치이고 정답의 외부 근거가 아니다.
외부 전문가 검수, 공식 출제기준 대조, 현행 법령 수치 확인, 난이도 검증은 미완료다.
미확인 법령 수치·소독 농도·접촉시간을 임의로 정답으로 넣지 않았다.
기본 JSON의 reviewed는 이 내부 검토 범위를 뜻하며 외부 검증을 뜻하지 않는다.

## 실제 점검

- 기존 90개 객체의 SHA-256을 고정해 ID·순서·본문·선택지·답안·해설·출처·검토 정보 보존을 단위 검사했다.
- 1,000개 모두 ID와 정규화 본문 및 본문+정렬 보기 중복 없음. 보기 순서가 바뀌어도 같은 본문·보기는 같은 지문으로 검사한다.
- 추가 910개 원고의 정규화 설명 및 정답 항목 이름은 각각 중복 없음.
- 원고의 정답 항목과 실제 JSON 정답 번호가 910개 모두 일치하며 각 문항의 네 보기 문자열은 서로 다름.
- 설명 안에 정답 항목명이 그대로 들어가 답을 노출하는 항목은 수정 후 검사했다.
- 문장 유사도가 높은 틴트/셰이드, 산성/알칼리성, 음이온/양이온 등은 서로 반대 개념의 비교로 검토했다.
  같은 설명을 반복한 문항이 아니라 각각 다른 관계를 구별하는 항목으로 유지했다.
- 감염원과 저장소는 직접 전파 출발점/자연 유지 기반의 차이를 명시했다.
- 호기·혐기는 산소 조건의 모호함을 줄여 절대호기성과 절대혐기성으로 명시했다.
- 펩타이드의 설명에 정답 용어가 포함되던 부분을 제거하고 단지형 용기의 표현을 정리했다.
- 진피의 바로 아래 위치, 현탁액의 큰 입자·침강과 콜로이드 특성, 양쪽성 계면활성제의 작용기 차이를 명시해 분류의 모호함을 줄였다.
- 의미 중복과 내용 정확성의 검토는 내부 검토다. 문자열 검사만으로 의미 중복 0이나 전문가 검수 완료를 보증하지 않는다.
- 모든 연도·회차는 null. 새 문항의 objectiveId와 learningObjective로 작성 원고의 단원·행을 추적할 수 있다.

## 재현과 권리

원고: scripts/makeup-items.txt 및 scripts/makeup-expanded.txt.
생성: `python3 scripts/generate-bank.py` (표준 라이브러리만 사용).
내용·고정 ID·보기 순서·정답 번호가 결정적이며 두 번 실행해 같은 JSON 해시를 확인했다.
자체 원고·문항은 CC BY 4.0. 민간 사이트나 공식 기출의 원문을 대량 복제하지 않았다.
학습 기록의 namespace와 기존 ID 참조는 변경하지 않는다.
배포 재시도 없이 기존 비배포 작업 브랜치에 데이터 변경을 보존한다.
