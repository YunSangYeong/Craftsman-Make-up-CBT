# Craftsman-Make-up-CBT
미용사(메이크업)

미용사(메이크업) 필기 학습용 React·TypeScript·Vite 정적 앱입니다.
전기기능사 CBT 기준 앱의 네이비·청록 반응형 화면과 학습 기능을 재사용했습니다.

## 기능

- 실전 모의시험: 전체 풀에서 고유 60문항, 절대 종료 시각 60분, 답안 변경·번호 이동·북마크·자동 제출·결과/전체 해설·오답 복습
- 랜덤: 전체/학습 영역, 순회 내 ID 중복 방지, 즉시 채점, 연속 정답과 정답률
- 두 모드 답안 선택/채점 후 Space 다음 문제. 마지막 문제에서 자동 제출하지 않음
- 오답노트·북마크·통계·최근 시험, JSON/CSV 등록·중복 제거·검증 대기·근거 입력 후 로컬 승인·양식/내보내기
- 메뉴 독립 세로 스크롤, 작은 높이·가로 화면·터치와 휠 지원. 학습 기준/버전 선택 없음
- 상단 상시 면책 배너 없음. 비공식 표시는 사이드바/푸터, 상세 확인 상태는 문제은행에 표시
- localStorage `makeup-cbt:v1`; 응답 최근 5,000개, 시험 최근 30회. 손상 원본 덮어쓰기 방지·저장 실패 경고
- JSON 학습 기록 백업 제공. 백업 복원 UI는 제공하지 않음. 초기화는 확인 후 개인 데이터만 제거

## 시험 규칙 확인 상태

공식 Q-Net 접근이 CONNECT 403으로 차단되어 **공식 규칙·현행 출제기준 확인 미완료**입니다.
60문항·60분·4지선다·100점 환산 60점 이상 합격·과락 없음은 학습용 가정입니다.
설정은 [src/qualification.ts](src/qualification.ts)에 분리했습니다. 세 영역 구분과 무작위 분포는 공식 과목별 배분을 뜻하지 않습니다.
미응답은 오답, 표시 점수는 소수 첫째 자리 반올림하되 합격 판정은 원비율을 사용합니다.
접근 시도 URL과 실제 오류, 검수 한계는 [검증 기록](docs/verification.md)에 기록했습니다.

AI 일반 지식으로 작성한 개념·상황형이며 내부 정답/해설 검토와 중복 검사 범위입니다.
전문가 독립 검수·공식 출제기준 대조·실제 시험 난이도 검증은 완료하지 않았습니다.
출제 연도와 회차는 모두 null입니다. 권리 미확인 외부 기출은 복사하지 않았습니다.
자체 문항은 CC BY 4.0, 재사용 앱 코드는 원본 MIT 고지를 보존합니다.
저장소 원고 링크는 작성 위치이며 외부 정답 증빙은 아닙니다.

## 로컬 개발

Node 24.19.0 (`.node-version`, engines >=22.12.0).

```sh
npm ci
npm run dev
npm test
npm run build
# Chromium을 별도로 설치한 일반 환경
npx playwright install --with-deps chromium
npm run test:e2e
# 이 클라우드 환경에 이미 설치된 Chromium 사용
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

`python3 scripts/generate-bank.py`로 원고에서 동일한 기본 JSON을 재생성할 수 있습니다.
생성은 출처·정답의 외부 검증을 대신하지 않습니다. 문제은행의 사용자 등록은 이 브라우저에만 저장되며 GitHub 공용 은행에 게시되지 않습니다.

## CI와 배포

요청받은 기본 흐름은 main push → validate (설치·단위·빌드·PC/모바일) → Pages deploy입니다.
PR은 검증만 하며 자동 재시도는 없습니다. Pages base는 `/Craftsman-Make-up-CBT/`입니다.
예상 기본 주소: https://YunSangYeong.github.io/Craftsman-Make-up-CBT/
이 주소의 존재나 현재 배포 성공을 아직 확인했다는 의미는 아닙니다.
배포 전 권한·네트워크 확인부터 첫 차단 시 재시도·우회·배포 유발 추가 푸시 없이 중단합니다.
원본 전기기능사 등 다른 프로젝트는 변경·재배포하지 않습니다.

- 이후 API/Pages 조회 재시도·workflow 실행·main push를 하지 않았습니다. CI/배포 실행 없음, 현재 게시 및 공개 화면 확인 안 됨.
